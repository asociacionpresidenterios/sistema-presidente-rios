# Sistema Asociación Presidente Ríos

MVP para registro y consulta de jugadores.

Campos: RUT, nombre completo, fecha de nacimiento, serie y club.

Incluye altas, edición, eliminación, búsqueda y API por RUT.
Preparado para PostgreSQL y Railway.

Próximas funciones: lector de RUT con cámara/OCR, fotos, credenciales,
usuarios por club, habilitación, tarjetas/suspensiones e importación Excel.
